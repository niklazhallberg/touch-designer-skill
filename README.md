# touch-designer-skill

A Claude Code skill for building TouchDesigner projects with Embody + Envoy MCP. Single-user today (Niklaz), structured to scale to a team without rebuild.

## What's in here

- `SKILL.md` — front door, loaded when Claude detects a TD context (`.toe`, `.embody/`, "TouchDesigner" mentioned).
- `skills/` — workflow recipes (load-on-demand: `create-operator`, `debug-operator`, `manage-annotations`, etc.). Canonical snapshots; Embody also auto-generates project-local copies.
- `rules/` — operational rules (parameter design, network layout, td-python gotchas, MCP safety). Same dual-life as skills.
- `references/` — knowledge banks loaded on trigger. Houses the skill-growth-protocol, TD-specific gotchas, patterns, and per-component notes.
- `scripts/td-new` — scaffolds a new TD project (folder + git + .gitignore + per-project settings stub) in 30 seconds. Lets Embody handle everything Embody-specific.
- `scripts/session-sync.sh` — SessionStart hook: pull latest, announce new learnings, silent on failure.
- `templates/td-project/` — what `td-new` copies into a fresh project folder.
- `CHANGELOG.md` — biography of what the skill has learned over time.

## Install on a new machine

```bash
git clone <repo-url> ~/.claude/skills/touch-designer-skill

# Add the SessionStart hook to ~/.claude/settings.json
# (see scripts/session-sync.sh header for the JSON snippet)
```

## Start a new TD project

```bash
cd ~/Projects/
~/.claude/skills/touch-designer-skill/scripts/td-new my-project
cd my-project
# Open TouchDesigner → Save As → my-project.toe → drag Embody.tox → set Aiclient=claude
claude
```

## Repo vs project — what lives where

| Lives in this repo (central, user-level) | Lives per TD project (auto-generated by Embody) |
|---|---|
| `SKILL.md`, `skills/`, `rules/`, `references/` | `<project>.toe`, `.mcp.json`, `.embody/envoy-bridge.py`, `.embody/envoy.json` |
| `CHANGELOG.md` (biography) | `CLAUDE.md`, `AGENTS.md`, `.claude/skills/`, `.claude/rules/` (Embody regen) |
| `scripts/td-new`, `scripts/session-sync.sh` | `.venv/`, `Backup/`, `TDImportCache/`, `logs/` (runtime) |
| `templates/td-project/` (the starter shell) | `.claude/settings.local.json` (per-machine perms allowlist) |

See `references/project-bootstrap.md` for the full split + Embody.tox sourcing.
